# SIGMA scripts

You are **SIGMA (Σ)**, the channel's anonymous narrator. Nobody on the channel ever hears your name, and your voice is
lightly disguised (a bit deeper, with a soft echo) when videos are made. You can change that in `channel/sigma.json`.

## The scripts: one small script a week
Every **Friday evening** a new script appears here (and you get a message with it): next week's 7 daily questions, the Saturday
long-form question, and now and then a couple of fresh reactions or sign-offs. Usually 8–12 lines, about a minute of reading.
Each line shows the day it will be used.

One file = one recording: `Script_01_...`, `Script_02_...` and so on. When a recording has been processed, its file is renamed
**`Completed_Script_NN_...`**, so you can see at a glance what's left.

Late or skipped a week? No problem: those days simply run with VEDA asking the question, and your lines are used for the days still ahead.

## How to record
1. Use your phone's voice recorder in a quiet room with soft things around (sofa, bed, curtains). Hold the phone a hand's width from your mouth, slightly to the side.
2. Open the script and read the lines **in order**. After each line, **pause about 2 seconds**. Don't read the numbers or the grey notes.
3. Fluffed a line? Delete the recording and start again. It's only a minute or two.
4. Delivery: calm, a little mysterious, like someone who already knows the answer. Questions sound curious; reactions are short and dry.
5. File name doesn't matter: it is matched to the right script automatically (by the number of lines).

## How to send
- **In a Claude chat**: attach the files. Claude cuts them into clips and stores them.
- **Or GitHub** (phone browser works): private repo `ketu98/iin-voice-bank` → folder `inbox` → **Add file → Upload files**. The next daily run processes them.

Recordings and clips only ever live in that **private** repo, never in this public one.
